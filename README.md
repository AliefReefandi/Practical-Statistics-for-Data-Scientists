## 📖 Tentang Repository

Repository ini berisi rangkuman teori dan implementasi kode dari setiap chapter dalam buku *Practical Statistics for Data Scientists*.

Setiap chapter dibuat dalam bentuk Jupyter Notebook (`.ipynb`) yang berisi:

- Ringkasan materi
- Penjelasan konsep dan teori
- Implementasi menggunakan Python
- Contoh analisis
- Kesimpulan dari setiap chapter

Tujuan dari repository ini adalah untuk memahami konsep statistik dan penerapannya dalam data science melalui praktik langsung menggunakan Python.
